# 公告來源與權利稽核

稽核日期：2026-08-30。這是工程風險紀錄，不是法律意見。

## 共通處理界線

- 只存取不需登入的 HTTPS 公開頁面，不繞過驗證、權限或技術限制。
- 僅保存搜尋所需的標題、日期、來源、官方連結與必要短摘要；完整內容與附件應回到官方網站閱讀。
- 不重新散布照片、作品、名單或完整附件；問校務遇到可識別個人資料時只提供官方入口。
- 來源主機固定在 allowlist；請求逾時 20 秒、同一序列請求至少間隔 1.5 秒，排程維持低頻。
- `robots.txt` 是爬取偏好而不是著作權授權；即使允許爬取，也不能取代著作權與個資判斷。

## robots.txt 狀態

2026-08-30 14:31 UTC 重新核對時，嘉中與嘉女的 `/robots.txt` 均回 HTTP 403，輔仁端點未在期限內取得可驗證回應。因此三校狀態仍是「未確認」，不能把 403、逾時或沒有讀到內容解釋成允許爬取。正式發布前應由維運者在一般網路環境逐一取得並保存日期、HTTP 狀態與內容雜湊；若出現禁止規則，立即停止對應路徑。
