DATA & RIGHTS

資料、隱私與權利說明

最後更新：2026-09-04。本頁是技術與使用說明，不是法律意見。

服務性質與資料來源

本站是非官方的校務公告索引與問答工具，只讀取各校不需登入即可瀏覽的公開頁面，以必要的標題、日期、摘要及官方連結協助查找。不得把本站答案視為校方正式決定；內容、期限與效力仍以原校公告為準。

來源：嘉義高中、嘉義女中、輔仁高中。

著作與引用

本站不主張取得原公告、附件、照片或其他內容的著作權。搜尋與問答只應使用完成目的所必要的短摘要並標示官方來源；第三方圖片、音樂、文章與附件不因出現在校網就當然成為開放授權資料。需要完整內容時請回到官方頁面。

個人資料與帳號功能

公告可能含公開聯絡方式或名單。問校務遇到姓名、學號、健康、成績、獎懲等可識別個人資料時，不整理或重述內容，只提供必要的官方入口。

若使用帳號與個人化功能，系統可能處理登入識別碼、所選學校與年級、選填班級、關注關鍵字、閱讀狀態、待辦及推播裝置資料，用於同步與提醒。班級與關注內容可不填；不要輸入身分證號、健康資料、成績、獎懲或他人的資料。雲端處理由專案已設定的 GitHub、Vercel 與 Supabase 基礎設施提供，實際儲存區域與契約仍須在正式啟用前核對。

Preview 帳號卡提供「刪除已同步資料」，可刪除偏好、追蹤、閱讀紀錄與待辦並清除該帳號的本機同步狀態；這不會刪除 Google 帳號或 Supabase Auth 登入識別。保存期限與尚未部署的自動清除控制詳見個人資料保存與刪除規格。

更正、停止使用與移除

公告內容有誤時，應先向原發布學校更正。若要本站停止顯示某個連結，可在 專案問題頁只提供公告網址或公告 ID；該頁是公開的，請勿張貼姓名、電話、學號、身分證號或其他個資。需要私密身分核對的案件，在專用私密聯絡管道建立前不得公開提交。

目前正式發布限制

技術控制不等於法律審查。2026-08-30 已完成線上資料庫的兩身分 RLS 隔離測試，跨帳號讀寫均被阻擋且測試資料已清除；但兩個專用、非正式用途的 Auth 使用者經 HTTP Data API 的端到端測試仍待 CI 完成。

發布檢查已分成公開公告核心、帳號個人化、帳密登入與提醒四個範圍。RLS、正式資料庫、密碼保護或提醒 schema 未完成時，只阻擋實際依賴它們的功能；不能用人工確認略過技術安全問題。

公開公告核心仍需就標題、必要短摘要與官方連結的具體使用範圍留下權利審查紀錄。沒有開放授權不會被系統自動判為合法或違法，技術閘門也不取代臺灣法律專業判斷。逐來源結果見公告來源與權利稽核。

參考法規：個人資料保護法、著作權法、刑法第 358 條。
