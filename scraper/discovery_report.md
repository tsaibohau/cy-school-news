# 第二輪補充探測

第一輪把「嘉女沒有細分類頁」寫成結論,**那是錯的**。第二輪找到正確的探測方式後,
兩校絕大多數分類頁都被找了出來,以下更正並補齊。

## 關鍵:分類 ID 不連續,掃區間找不到

首頁頁籤(考試訊息、升學資訊、防疫專區……)的內容是 JavaScript 動態載入的,
靜態 HTML 裡一則公告都沒有,頁籤內也沒有 MORE 連結,因此第一輪完全看不到它們。
真正的線索在頁籤區塊裡的這行 script:

```
$.hajaxOpenUrl('/app/index.php?Action=mobileloadmod&Type=mobile_rcg_mstr&Nbr=401', ...)
```

其中的 **`Nbr` 就是分類 ID**,對應 `/p/403-{unit}-{Nbr}-1.php`。
以「校園訊息 Nbr=12」對照已知的 `403-1008-12` 驗證無誤後,即可反查所有頁籤。

實測 ID 分布在 **11～742** 之間且高度不連續,所以掃描 ID 區間注定會漏 —— 這也解釋了
為什麼 `403-1008-41..75` 全數 404、而嘉女 495–535 / 775–800 只掃到 3 頁。
此邏輯已寫回 `discover.py` 的 `homepage_tabs()`。
